# Tarot Compass

Tarot Compass 是一個線上塔羅抽牌工具。

選擇牌組與抽牌張數後即可開始抽牌，系統會隨機產生牌面與正逆位。抽牌設定與歷史紀錄會保存在目前的瀏覽器中，重新整理頁面後仍可保留。

## 用途

提供日常占卜與塔羅練習使用，讓使用者可以快速完成抽牌並查看結果，不需要另外準備實體牌卡。

## 功能

### 抽牌

- 可選擇大阿爾卡納（22 張）或完整牌組（78 張）
- 可自訂抽牌張數
- 每張牌會隨機產生正位或逆位
- 顯示牌名與正逆位
- 提供發牌與翻牌動畫，並可選擇略過動畫
- 牌面會依照畫面寬度自動調整排列方式
- 可一鍵複製完整抽牌結果

### 歷史紀錄

- 每次抽牌完成後自動新增一筆紀錄
- 最多保留最近 10 次抽牌結果
- 紀錄內容包含抽牌時間、張數、牌名與正逆位
- 可單獨複製指定紀錄
- 可一次清除全部歷史紀錄
- 清除前會再次確認，刪除後無法復原
